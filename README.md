# Imersão Alura com Google Gemini
Projeto de imersão da Alura com Google Gemini que visa a construção de uma base de conhecimento de tecnologias para desenvolvedores.
O objetivo da imersão foi desenvolver uma pagina do zero, utilizando o Gemini para auxiliar na criação e correção dos códigos, algo bastante gratificante, pois viabilizou a construção rapida do projeto, visto que auxiliou na correção dos bugs que foram surgindo no projetos, assim como na criação da base de dados, diminuindo assim o tempo de pesquisa e estruturação.

O que começou como uma prática de HTML/CSS evoluiu para uma aplicação dinâmica, com o uso JavaScript puro, premitindo manipular dados e criar animações.

## Funcionalidades Principais
- Carregamento dos dados vindos do JSON em card ao carregar a pagina;
- sistema de busca que carregar os dados pesquisados em um modal, ao clicar no botão buscar;
- foram colocadas animações de entrada ao acessar a pagina utilizando o Gemini Code Assist para geração do código de animação;
- O Gemini Code Assist também foi usado para popular o arquivo JSON;
